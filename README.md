# De' Vesa Woods — Woody Demo

Public website demo for De' Vesa Woods with the ElevenLabs “Talk to Woody” voice and chat widget.

## Demo boundaries

- The website inquiry form is a visual preview and does not deliver messages.
- Woody can answer approved cabinetry questions and use the connected demo calendar flow.
- A live business phone number, SMS reminders, email notifications, CRM, and call transfer are not connected.
- Images labeled “Design concept” are illustrative.

No API keys or private credentials are included in this repository.
